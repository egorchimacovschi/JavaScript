# JavaScript

My dedication to JavaScript — a personal collection of exercises, mini-programs, and small practice projects, organized by folder.

## 📁 Repository Structure

| Folder | Content |
|---|---|
| [`Learning`](./Learning) | Core JavaScript concepts: variables, data types, operators, conditionals, loops, functions, arrays/objects, DOM manipulation, events, and small practice exercises/programs |

More folders (e.g. standalone projects built on top of `Learning`) will be added here as new topics are covered.

Each folder has its own `README.md` with more detail on what's inside.

## ⚙️ Requirements

- A modern web browser (for exercises that use the DOM/browser APIs)
- [Node.js](https://nodejs.org/) (for exercises run outside the browser)

No external packages are required to run the basic exercises.

## 🚀 Running

Most files are standalone scripts. Depending on the exercise:

- **Browser-based files:** open the corresponding `.html` file in your browser.
- **Node-based files:** run directly with:
```bash
node <folder>/<file>.js
```

## 📌 Notes

- This repository is a personal learning log and grows as new topics are covered.
- Files are individual exercises/labs; most don't depend on each other, aside from a few that import a shared helper file from within the same folder.
